We're excited to announce that all tables across all FAST modules now have custom icons, improving visual recognition and navigation throughout the model-driven applications.

## What's New

Every table in every module now includes a distinctive icon that appears:

- **In navigation** – Quickly identify tables in app navigation menus and site maps
- **In views and grids** – Recognize record types at a glance when browsing data
- **In lookups** – Distinguish between different entity types when selecting related records
- **In forms** – Visual indicators help users understand which table they're working with

These custom icons replace generic default table icons with purpose-built visuals that reflect the nature of each entity, whether it's assets, cases, projects, people, or other business objects.

## Why This Matters

Custom icons provide immediate visual context that helps users:

- **Navigate faster** – Recognize tables without reading labels, especially when working across multiple modules
- **Reduce cognitive load** – Visual cues make it easier to distinguish between similar table names
- **Improve user experience** – Professional, consistent iconography creates a more polished application interface
- **Support accessibility** – Icons supplement text labels for users who benefit from visual aids

## Scope

This update touches all tables across all 20+ modules in the FAST ecosystem, including:

- Core foundation entities (organizations, locations, contacts, documents)
- Module-specific tables (assets, cases, projects, investigations, events, and more)
- Supporting reference data tables (categories, types, statuses, priorities)
- Relationship and junction tables (assignments, links, associations)

Organizations can customize these icons further to match their own branding or visual standards, but now have a strong baseline set of professional icons right out of the box.

## Technical Details

Icons are configured through the Dataverse table metadata and will persist through solution upgrades. If you've already installed FAST modules, update to the latest releases to get the custom icons in your existing environments.
