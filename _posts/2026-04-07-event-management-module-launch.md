We're excited to announce the **Event Management** module — a starter kit for planning, organizing, and executing events with comprehensive registration, session scheduling, and participant tracking.

## What is the Event Management Module?

The Event Management module provides structured data capture for managing events from planning through execution. It enables organizations to define event details and classifications, manage participant registration and tracking across multiple roles, organize sessions into thematic tracks with scheduling and capacity management, capture presentation and exhibition submissions with review workflows, coordinate event sponsors and partnerships, process event requests and approvals, and track participant check-ins and attendance.

Key capabilities include:

- **Event Planning** – Define events with classification, format (in-person, virtual, hybrid), dates, locations, and status tracking through planning, registration, and execution phases
- **Request and Approval** – Capture proposed events with intake workflows and approval processes before formal event creation
- **Participant Management** – Register and track attendees, speakers, presenters, panelists, staff, volunteers, exhibitors, and VIPs with role-based tracking
- **Registration Tracking** – Manage participation status (invited, registered, confirmed, waitlisted, checked-in), payment status, and certificate issuance
- **Session Scheduling** – Create scheduled time blocks with locations, capacity management, and current registration tracking
- **Track Organization** – Group sessions into thematic or organizational tracks with hierarchical track structures for complex events
- **Submission Management** – Capture presentations, posters, exhibitions, or demonstrations with review and approval workflows
- **Session Participation** – Link participants to specific sessions when roles or attendance differ by session
- **Sponsorship Coordination** – Document sponsors,sponsorship levels, contribution amounts, agreements, and benefit fulfillment

## What's Included

This initial release (v1.1.0.0) provides the foundational data model:

- **9 entities** providing comprehensive event lifecycle management
- **Integration with Core module** for persons, organizations, locations, documents, and agreements

Forms and views for event planning, registration management, session scheduling, and participant tracking will be available in an upcoming release. The module provides implementors with a baseline data structure that can be customized for conference management, training coordination, public engagement programs, community events, professional development workshops, and virtual or hybrid event platforms.

## Getting Started

The Event Management module is available in the [FAST Modules Repository](https://github.com/microsoft/industry-apps) under the MIT license. It requires the Core module as a foundation.
