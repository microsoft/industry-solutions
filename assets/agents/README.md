# AI Agents - Assets Directory

This directory contains assets for AI Agents including thumbnails and screenshots.

## Structure

- `{agent-slug}/` - Directory for each agent containing screenshots
- `{agent-slug}.png` - Thumbnail image for agent card (optional, if not using a shared thumbnail)

## Current Agents

### Asset Management Agent
- **Thumbnail**: Currently using `/assets/use_cases/asset-management.png` (can be customized)
- **Screenshots**: Upload to `asset-management-agent/sample.png`

## Adding New Assets

1. Create a directory for the agent: `{agent-slug}/`
2. Add screenshots with meaningful names (e.g., `sample.png`, `dashboard.png`)
3. Optionally create a custom thumbnail: `{agent-slug}.png`
